# Cinematic UI Guidelines

## Direction

Neural Ops should feel like a futuristic recruiting operating system: dark graphite, glass panels, subtle glow, structured operational layouts, and intelligent motion.

## Do

- Use ultra-dark graphite backgrounds.
- Use glass panels with low-opacity borders.
- Use cyan for active commands and live operational state.
- Use violet for AI and ranking context.
- Use amber sparingly for processing and attention.
- Keep layouts dense enough for repeated recruiter work.
- Prefer explicit empty states over fake metrics.
- Use subtle hover movement and scanline animation only where it supports atmosphere.

## Do Not

- Do not use rainbow gradients.
- Do not use heavy neon everywhere.
- Do not make the interface feel like a game HUD.
- Do not add fake testimonials, fake stats, or mock analytics.
- Do not hide primary workflows behind marketing sections.
- Do not create disconnected page-level sidebars.

## Page-Level Guidance

Landing should feel like entering the AI operations system.

Dashboard should render from the top as mission control with real backend data.

Documents should feel like candidate intelligence ingestion.

Search should feel like a neural terminal with ranking and relevance signals.

Copilot should feel like an operational assistant console, not a generic chatbot card.
