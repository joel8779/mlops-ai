# Recruiter Workflow Design

Neural Ops should feel like an AI recruiting operations center.

## Primary Workflow

1. Create or upload a JD.
2. Open that job.
3. Review parsed JD intelligence.
4. Upload resumes.
5. Generate or refresh ranked candidates for the job.
6. Inspect ATS explanations and semantic match evidence.
7. Shortlist or reject candidates in the job context.
8. Use analytics to monitor coverage, gaps, and pipeline activity.

## Job Detail Page

The job intelligence page shows:

- JD summary and extracted skills.
- Required experience.
- Semantic insights.
- ATS-ranked candidates.
- Match explanations.
- Skill gaps.
- Shortlist/reject actions.

## Candidate Profile

The global candidate page remains a dossier. It does not compute ATS scores because a global candidate score is not meaningful without a selected job.
