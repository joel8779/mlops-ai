# Neural Ops Design System

## Product Identity

Neural Ops is a cyberpunk recruiting command center: cinematic, operational, premium, and backend-connected. The UI should feel like recruiter mission control, not a generic AI SaaS template.

## Palette

| Token | Value | Usage |
| --- | --- | --- |
| Background core | `#09090B` | App base |
| Background surface | `#0F1115` | Elevated zones |
| Background elevated | `#151821` | Inputs and tactical wells |
| Panel | `rgba(20,24,32,0.78)` | Glass panels |
| Border | `rgba(255,255,255,0.08)` | Panel and control separation |
| Primary accent | `#38BDF8` | Active states, command buttons, live indicators |
| Secondary accent | `#8B5CF6` | AI and ranking context |
| Warning | `#F59E0B` | Attention and processing highlights |
| Text primary | `#F8FAFC` | Primary copy |
| Text muted | `#CBD5E1` | Secondary copy |
| Text subtle | `#64748B` | Labels and metadata |

## Core CSS Utilities

| Utility | Purpose |
| --- | --- |
| `.neural-bg` | Ambient graphite background with restrained cyan, violet, and amber depth |
| `.ops-grid` | Subtle operational grid field |
| `.ops-panel` | Glass operational panel |
| `.ops-panel-strong` | Higher-emphasis command panel |
| `.holo-border` | Subtle holographic border treatment |
| `.scanline` | Slow cinematic scan overlay |
| `.ops-chip` | Metadata and skill tokens |
| `.ops-input` | Tactical form inputs |
| `.ops-button` | Primary command button |
| `.ops-button-secondary` | Secondary operational action |

## Motion

Motion is restrained: scanlines, hover lifts, active glows, and state transitions. No neon spam, no gaming effects, and no excessive looping animation.
