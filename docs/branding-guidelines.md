# Branding Guidelines

## Overview

This document defines the brand identity for Resume AI, an AI-native recruiting platform. The brand conveys innovation, intelligence, and premium quality through a futuristic, dark-mode-first aesthetic.

## Brand Identity

### Brand Name
- **Name:** Resume AI
- **Tagline:** Intelligent Hiring
- **Positioning:** AI-powered recruiting infrastructure for modern teams

### Brand Personality
- **Innovative:** Cutting-edge AI technology
- **Intelligent:** Smart, data-driven decisions
- **Premium:** High-quality, enterprise-grade
- **Futuristic:** Forward-thinking, modern
- **Trustworthy:** Reliable, secure, professional

## Logo

### Primary Logo
- **Style:** Wordmark with spark icon
- **Icon:** Sparkles (Lucide icon)
- **Typography:** Bold, sans-serif
- **Color:** White on dark background
- **Usage:** Primary brand identifier

### Logo Variants
- **Dark mode:** White text on black background
- **Light mode:** Violet gradient text on white background
- **Icon only:** Spark icon for small spaces
- **Horizontal:** Standard layout
- **Stacked:** Vertical layout for constrained spaces

### Logo Usage Guidelines
- **Minimum size:** 24px height
- **Clear space:** 1x logo height on all sides
- **Don't:** Stretch, rotate, or modify
- **Don't:** Use on busy backgrounds
- **Do:** Maintain aspect ratio
- **Do:** Use approved color variations

## Typography

### Font Family
- **Primary:** System sans-serif
  - Fallback: Inter, SF Pro, Segoe UI, Roboto, Arial
  - Usage: Body text, headings, UI elements

- **Monospace:** System monospace
  - Fallback: SF Mono, Monaco, Consolas
  - Usage: Code snippets, technical content

### Type Scale
- **Display:** 4.5rem (72px) - Hero headlines
- **H1:** 3rem (48px) - Page titles
- **H2:** 2.25rem (36px) - Section titles
- **H3:** 1.875rem (30px) - Card titles
- **H4:** 1.5rem (24px) - Subsection titles
- **Body Large:** 1.125rem (18px) - Lead text
- **Body:** 1rem (16px) - Body text
- **Body Small:** 0.875rem (14px) - Captions, labels
- **Caption:** 0.75rem (12px) - Fine print

### Font Weights
- **Light:** 300 - Optional for large display
- **Regular:** 400 - Body text
- **Medium:** 500 - Emphasis
- **Semibold:** 600 - Headings, buttons
- **Bold:** 700 - Strong emphasis

### Line Height
- **Tight:** 1.25 - Headings
- **Normal:** 1.5 - Body text
- **Relaxed:** 1.75 - Large text

## Visual Elements

### Glassmorphism
- **Background:** Semi-transparent gradient
- **Backdrop blur:** 8-16px
- **Border:** Thin, semi-transparent white
- **Usage:** Cards, panels, overlays

### Gradients
- **Primary:** Violet to Blue
- **Secondary:** Blue to Cyan
- **Accent:** Violet to Purple
- **Subtle:** Slate to transparent
- **Usage:** Buttons, cards, backgrounds

### Shadows
- **Subtle:** Small elevation
- **Medium:** Standard elevation
- **Large:** High elevation
- **Glow:** Colored glow for emphasis
- **Usage:** Cards, modals, dropdowns

### Borders
- **Thin:** 1px, subtle separation
- **Medium:** 2px, clear separation
- **Thick:** 4px, emphasis
- **Color:** White/10, white/20, violet/30

## Spacing System

### Scale
- **1:** 4px - Micro spacing
- **2:** 8px - Small spacing
- **3:** 12px - Medium spacing
- **4:** 16px - Standard spacing
- **6:** 24px - Large spacing
- **8:** 32px - Extra large spacing
- **12:** 48px - Section spacing
- **16:** 64px - Page spacing

### Usage Guidelines
- **Consistent:** Use scale values, not arbitrary
- **Rhythm:** Maintain consistent spacing patterns
- **Breathing room:** Allow space between elements
- **Alignment:** Align to grid when possible

## Motion & Animation

### Animation Principles
- **Purposeful:** Every animation has a purpose
- **Subtle:** Don't overwhelm users
- **Smooth:** Use easing functions
- **Fast:** Keep durations short (200-500ms)
- **Consistent:** Use similar patterns throughout

### Common Animations
- **Fade in:** Opacity 0 to 1
- **Slide up:** Translate Y 20px to 0
- **Scale:** 0.95 to 1.0
- **Hover:** Scale 1.0 to 1.02
- **Tap:** Scale 1.0 to 0.98

### Easing Functions
- **Ease-out:** For entrance animations
- **Ease-in-out:** For continuous motion
- **Spring:** For bouncy interactions
- **Linear:** For continuous loops

### Duration Guidelines
- **Micro:** 100-200ms - Hover states
- **Short:** 200-300ms - Button clicks
- **Medium:** 300-500ms - Page transitions
- **Long:** 500-1000ms - Complex animations
